# leetCode

This repository is used to store and push LeetCode problem solutions. Solutions are automatically added by the LeetPush extension: https://github.com/LeetPushExtension/LeetPush.

Languages
- Python (primary)
- Java (small portion)

Repository structure
- problems/
  - <platform>/<problem-id>_<problem-name>/
    - solution.py  # primary solution file (Python)
    - README.md    # problem description, approach, complexity
    - tests/       # optional tests

How to run solutions
1. Navigate to a problem folder under `problems/`.
2. Run the Python solution with: `python solution.py` (or use your test harness if provided).

Contributing
- This repo is primarily populated by the LeetPush browser extension. If you'd like to add or improve solutions manually, open a PR with a well-documented solution and include problem explanation and complexity analysis in the problem's README.md.
